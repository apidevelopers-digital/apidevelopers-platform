# Roadmap

Status: Active  
Owner: API Developers.digital

## North Star

Build a global, multi-tenant technology platform that serves `uni.` and external customers with versioned APIs, engines, SDKs and enterprise-grade governance.

## Phase 1 — Global Foundation

Target: 2026

- establish the official repository layout
- complete legacy inventory
- migrate neutral contracts
- migrate events, audit, guard and memory
- harden Conversation and Workflow Engines
- define gateway, auth, tenancy and observability
- keep `uni.` production services stable

## Phase 2 — Productization

Target: 2027–2028

- publish Developer Portal and API Console
- provide sandbox, API keys and OAuth
- ship official SDKs
- implement usage, billing and SLAs
- release WhatsApp, Instagram, Email and WebChat services
- provide workflow templates and action catalogs

## Phase 3 — Internationalization

Target: 2028–2030

- multilingual documentation and support
- multi-currency billing
- multi-region runtimes
- regional data residency
- GDPR, LGPD and sector-specific compliance
- partner and integrator programs

## Phase 4 — Ecosystem

Target: 2030–2032

- public Action Registry
- marketplace for APIs, SDKs, connectors and workflows
- certified partners
- revenue sharing
- enterprise white-label
- domain-specific platform services

## Phase 5 — Global Infrastructure

Target: 2032–2036

- multi-cloud operation
- global marketplace
- enterprise agent runtime
- regional compliance modules
- strategic partnerships and acquisitions
