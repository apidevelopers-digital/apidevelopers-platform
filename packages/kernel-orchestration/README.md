# @apidevelopers/kernel-orchestration

Núcleo inicial de orquestração institucional.

## Incluído no marco 0.1.0

- contrato de missão;
- manifesto de agente;
- contrato de atribuição;
- máquina de estados;
- orçamento computacional básico;
- validadores determinísticos;
- testes unitários.

Este pacote ainda não executa modelos, ferramentas ou ações externas. Ele é deliberadamente determinístico e sem efeitos colaterais.

## Execução de testes

```bash
node --test packages/kernel-orchestration/test
```
