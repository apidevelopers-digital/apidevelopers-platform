# @apidevelopers/kernel-reflection

Deterministic, advisory reflection over institutional knowledge snapshots.

## Canonical role

Reflection remains in the cognitive execution route:

`kernel-reasoning → kernel-reflection → kernel-planning`

The promotion order of packages does not redefine this runtime route.

## Rules

- `REF-001`: orphan nodes.
- `REF-002`: capabilities without assets.
- `REF-003`: assets without evidence.
- `REF-004`: active organizations without solutions.

## Invariants

- advisory mode only;
- no mutation or execution authority;
- deterministic findings;
- input snapshot remains unchanged;
- governed handoff must come from `kernel-reasoning`;
- next handoff is emitted only to `kernel-planning`.
